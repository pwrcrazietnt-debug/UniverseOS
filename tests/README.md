# Test strategy

Compatibility must be demonstrated through repeatable tests.

Future test suites should cover:
- File identification without execution.
- Malformed and adversarial package inputs.
- Architecture and dependency mismatches.
- Permission and privilege boundaries.
- Install, update, rollback, launch, and uninstall behavior.
- Runtime health and failure reporting.
- Hardware-specific graphics, audio, input, and networking behavior.

Never use software or assets without the right to test or redistribute them.
